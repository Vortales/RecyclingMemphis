# Законопроекты

14 файлов ACT в папке `Законопроекты`; отдельные объяснения — в `Пояснения`.
Начните с `Пояснения/00 — Обзор пакета и взаимосвязи.docx`.

## Воспроизводимость

Исходники не изменяются. Для обновления после добавления нового файла:

1. Установить Python и `python-docx` (зафиксированная версия в requirements.txt).
2. Выполнить `Анализ/index_sources.py`.
3. Повторно содержательно проверить новые нормы и связи; сценарии **не делают** автоматического юридического заключения.
4. Обновить `prepare_bills.py` и тематические выводы `report.py`, затем выполнить их вместе с `render_docs.py`.
5. Запустить `validate.py`.

`база.json` — полные исходные тексты, статьи, SHA-256; `проекты.json` — редакции и объяснения; `манифест.json` — соответствие файлов; `матрица_465_пар.csv` — все пары по четырем осям; это навигация, не гарантия отсутствия иных коллизий.

В источнике 147.txt двойная статья 11 сохранена целиком в левой колонке. В 156.txt вложенные цитаты дорожных статей не считаются новыми статьями закона. В 163.txt приведены полные главы. Отсутствующий заголовок 172.txt идентифицирован по прямой ссылке из 162.txt. Номера ACT рабочие.
